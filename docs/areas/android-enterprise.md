## 1. Objectives

- Understand Android Enterprise architecture.
- Explore Android enrollment methods.
- Identify corporate and BYOD management scenarios.
- Understand application protection policies.
- Review device compliance and security.

## 2. Enrollment Models

| Enrollment type | Description |
|---|---|
| Fully Managed | Corporate-owned device, fully managed |
| Corporate-owned with Work Profile | Corporate device with separated work and personal data |
| Personally Owned Work Profile | Personal device with a managed work profile |
| Dedicated Device | Corporate device for a specific organizational purpose |

- Application assignments.

## 5. Security and Compliance

Important configuration areas:

- Screen lock requirements.
- Encryption requirements.
- Minimum operating system version.
- Device integrity.
- Work profile protection.
- Organizational data protection.

## 6. Validation

Validation should include:

- Reviewing enrollment status.
- Checking device compliance.
- Verifying managed applications.
- Reviewing policy deployment.
- Investigating enrollment errors.

## 7. Implementation Considerations

- Select enrollment methods according to ownership.
- Understand privacy boundaries in BYOD.
- Apply appropriate application protection.
- Test policies before broad deployment.
- Communicate user enrollment requirements.

## Key Takeaways

- Android Enterprise supports multiple ownership models.
- Work Profiles separate organizational and personal data.
- Intune centralizes Android device management.
- Application protection helps secure corporate information.
